# J SPA — Implementation Summary (`IMPLEMENTATION.md`)

## Modular Code Organization
The monolith `server.mjs` and single-line `public/app.js` were refactored into cohesive, readable modules while preserving zero external runtime dependencies and full API/SQLite compatibility (`CONTRACT.md`):

### Backend (`server/` + `server.mjs` + `seo.mjs`)
- `server/validation.mjs`: Input validation, Saudi mobile normalization & masking (`9665XXXXXXXX` / `9665****XX`), halala money math, safe URL validation, WhatsApp deep-link builder.
- `server/auth.mjs`: Argon2id hashing + legacy scrypt backward compatibility, token/hash utilities, session cookie helper, rate limiting, employee customer projection masking.
- `server/db.mjs`: SQLite WAL initialization, additive indexes, all 13 richly described services and 4 provisional packages, additive customer/experience tables (`passport_favorites`, `nail_styles`, `passport_prefs`, `group_requests`, `gift_requests`, `funnel_events`), plus non-destructive upgrade logic preserving owner edits on existing databases.
- `server/experiences.mjs`: Privacy-safe aggregate `funnel_events` telemetry, deterministic explainable **J Ritual Studio** recommendations strictly bound to active catalog & credential rules, **Nail Atelier** (`Almond`, `Oval`, `Soft Square`, `Square`, `Coffin`) save & public share-code lookups, **Beauty Passport** favorites/preferences/last-booking helpers, **Occasion Experiences (`تنسيق جلسات المناسبات`)** requests, and **Gift a Ritual** manual payment-verified voucher requests.
- `server/loyalty.mjs`: Atomic `reconcileLoyalty`, reward request creation, atomic commit/cancel processing, negative-balance rollback protection.
- `server/booking.mjs`: Asia/Riyadh scheduling & capacity conflict verification, idempotent `pending_confirmation` creation, status state machine, verified payment timestamp recording (`payment_verified_at`), cumulative refunds.
- `server/admin.mjs`: Role-based paginated `GET /api/admin` projections (least-privilege employee scoping vs. full owner telemetry including `analytics.funnel` and pagination metadata), verification approval, recovery token creation, occasion & gift status/payment verification handlers, tri-state review moderation (`approved | pending | needs_edit`), and catalog/settings/staff handlers.
- `seo.mjs`: Per-route titles, descriptions, canonical + `hreflang` (`ar-SA`, `en-SA`, `x-default`), Open Graph (`og:*`) + Twitter meta tags, canonical `occasions` metadata, `isKnownAppRoute()` HTTP `404` enforcement for unknown `/ar/*` & `/en/*` URLs, `HealthAndBeautyBusiness` & `Service` JSON-LD (no fabricated ratings or street addresses), and semantic SSR HTML injection for public routes.
- `server.mjs`: Security headers, strict static asset boundary, HTTP `301` redirect from `/[ar|en]/group-booking` to `/[ar|en]/occasions`, HTTP 404 SSR handling on unknown paths, review creation/editing (`moderation_status`), experience/passport/telemetry/admin routes, `createApp()`, and `--create-owner` CLI bootstrap.

### Frontend (`public/` + `public/js/`)
- `public/index.html` & `public/styles.css`: Self-hosted SIL OFL typography (`>= 13px` enforced floor), responsive RTL/LTR design tokens, visibility-first `[data-reveal]` styles, archival `.petal-cameo` & `.petal-progress-*` styles, `.auth-shell` split layout, `.occasion-svc-grid` checkbox pills, `.atelier-hand-canvas`, `.progress.five` single-bar mobile stepper, `#EED8B8` accessible plum eyebrows, `@media (max-width: 780px)` card tables, high-contrast `#toast` border, and `360px` header tuning.
- `public/js/state.js`: Shared client state (including `favorites`, `atelier`, `studio`, Saudi-localized `groupDraft`, pagination state, client `group-booking -> occasions` redirect, `passport` route alias), `num(v)` Western-digit formatter (`ar-SA-u-nu-latn` / `en-US`), CSRF fetch wrapper, i18n & `<bdi>`-safe currency/duration formatters.
- `public/js/motion.js`: Visibility-first `initScrollReveals()` (marks `[data-reveal]` `.is-revealed` immediately), privacy-safe `trackFunnel()` client helper, and Pierre-Joseph Redouté archival botanical oval cameo renderer (`renderSignatureBloomSVG` using `rose-bloom.webp` / `rose-damascena.webp`).
- `public/js/components.js`: Original SVG monogram (`currentColor` footer support), stroke icons (`star`, `calendar`, `check`, `heart`, etc.), unified header/footer Madinah lockups, eager `serviceArt`, Favorite toggles, accessible **5-star `openReviewModal`**, `reviewModerationStatusBadge`, `reviewAuthorName`, confirm action dialog, and responsive `simpleTable`.
- `public/js/pages-public.js`: Redesigned Saudi MSA Homepage (Hero, Choose Your Mood, Featured Rituals, compact `01–04` Home Visit Timeline, Atelier `<canvas>` Preview, J Petals Archival Cameo band, Honest Care Standards, Final CTA), Services catalog (`role="group"` + `aria-pressed`), Service details, Packages, interactive Reviews page (`#open-review-cta` + client review statuses), About, Contact, FAQ, Policies, Privacy, Terms, Recovery, and 404 view.
- `public/js/atelier.js`: `720×720` HTML5 `<canvas>` Photographic 2.5D Studio Compositor over `/assets/images/atelier-hand-base.webp` with cached melanin skin buffers (`fair`, `warm`, `olive`, `deep`), 5 shapes (`almond`, `oval`, `squoval`, `square`, `coffin`), 3 lengths, 10 polish shades, 5 French/ombré modes, pointer-reactive `lightX` finishes, split Steps 5 & 6 controls, share-code workflow, Save to Passport, and direct booking.
- `public/js/experiences.js`: **J Ritual Studio** (`/studio`) with tactile `[data-studio-opt]` buttons + immediate auto-matched cards, **Beauty Lookbook** (`/lookbook`), 2-column **Occasion Experiences (`تنسيق جلسات المناسبات`)** (`/occasions`) with `[data-guest-svc]` checkbox pills & editable default date, and **Gift a Ritual** (`/gifts`).
- `public/js/booking.js`: 5-step mobile-first Booking Wizard (`Category` -> `Ritual` -> `Time` -> `Details` -> `Review`) with `.progress.five` horizontal mobile bar, `.form-actions.single-action` aligned Step 1 CTA, returning-customer `"إعادة طلب آخر زيارة"` shortcut, smart working-day/blocked-date chips, incremental summary DOM updates, `<bdi>` numeric formatting, and WhatsApp manual-send guidance.
- `public/js/account.js`: Split `.auth-shell` Auth forms (`h1`) + Passport companion card, **My Beauty Passport** (Bookings + 1-tap `Rebook` + 5-star review trigger/status, Favorites, Saved Nail Atelier Styles, Preferences + reminder opt-in, Occasion & Gift Requests), manual WhatsApp verification instructions, and Ivory Gallery **J Petals Club** cameo reward meter.
- `public/js/admin.js`: Role-aware live-reloading dashboard adding **Occasions & Gifts** tab, Owner **Digital Funnel Metrics** breakdown, tri-state Review Moderation (`Approve publication` / `Keep pending` / `Needs revision`), table pagination, and confirmation dialogs before irreversible refunds, reward executions, and staff revocations.
- `public/concepts.html`, `public/concepts.css`, `public/concepts.js`: Interactive 4-direction design studio (`Luxury Synthesis`, `Botanical Ritual`, `Modern Blush`, `Luxury Editorial`) with Desktop/Mobile Hero toggle.
