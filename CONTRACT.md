# J Beauty — Platform Integration Contract
Node 24 LTS (`>= 24.18`), zero external runtime npm dependencies, `node:sqlite`, vanilla HTML/CSS/ESM JavaScript. Run dual isolated origins via `node server.mjs` (Customer Portal at `http://127.0.0.1:3000`, Operations Portal at `http://127.0.0.1:3100`) or launch standalone listeners via `node server/customer-server.mjs` and `node server/ops-server.mjs`. All API responses return JSON (`{...}` or `{error}`); cookie sessions are host-only without a `Domain` attribute (`jb_customer_session` vs `jb_ops_session`, `__Host-` prefixed in TLS production) and enforce matching `app_scope` (`customer` vs `ops`), strict origin validation, and `X-CSRF-Token` headers on all state mutations.

## Customer Origin (`apps/customer`, `:3000`)
- `GET /api/session` => `{ user: null | {id,name,phone,role:'customer',verified}, csrfToken }`
- `GET /api/catalog` => `{ services, packages, settings, reviews }` (`services` active catalog with curated pricing/durations/categories; `packages` computed from component totals; `reviews` published/approved only).
- `POST /api/register` `{ name, phone, password, passwordConfirmation, terms: true }`; `POST /api/login` `{ phone, password }` (rejects staff roles with `403`); `POST /api/logout {}`.
- `POST /api/verification/request {}` => `{ reference, expires_at, whatsapp_url }`; `POST /api/reset { token, password }`.
- `POST /api/bookings` `{ service_ids: [], package_id: null, date: 'YYYY-MM-DD', time: 'HH:mm', name, phone, neighborhood, notes, terms: true, idempotency_key }` => `{ booking, whatsapp_url, message }`.
- `POST /api/group-requests` `{ organizer_name, organizer_phone, date, time, neighborhood, participants: [{label, service_ids:[]}], notes?, terms: true }` => `{ group_request, message, whatsapp_url }`.
- `POST /api/gift-requests` `{ sender_name, sender_phone, recipient_name, personal_message?, package_id? | service_id?, terms: true }`.
- `GET /api/account` => `{ user, bookings, ledger, balance, has_pending_entitlement, rewards, reward_requests, reviews, passport }`.
- `POST /api/rewards/request { reward_id }`; `POST /api/reviews { booking_id, rating, body, display_name, edit? }`; `/api/atelier/styles*`; `/api/passport/*`; `/api/studio/recommend`; `/api/telemetry/event`.
- Routes `/ar/admin*`, `/en/admin*`, `/api/admin*`, and `/api/ops*` return `404` (`X-Robots-Tag: noindex, nofollow` on HTML 404).

## Operations Origin (`apps/staff`, `:3100`)
- Enforces `X-Robots-Tag: noindex, nofollow` and `Cache-Control: no-store`. Rejects customer roles at `/api/ops/login` (`403`).
- `GET /api/ops/session` => `{ user, csrfToken, mfa: { required, enabled, verified, setup_required, mode }, customerOrigin }`
- `POST /api/ops/login { phone, password, totp_code? }`; `POST /api/ops/mfa/setup {}` => `{ secret, otpauth_uri, recovery_codes }`; `POST /api/ops/mfa/verify { code? | recovery_code? }`; `POST /api/ops/logout {}`.
- Every `/api/ops/*` business route enforces staff session, mandatory MFA check (`OPS_MFA_REQUIRED=all` in production), and explicit fine-grained capabilities (`bookings.read`, `bookings.read_assigned`, `bookings.confirm`, `bookings.assign`, `bookings.update`, `bookings.update_status_basic`, `bookings.update_assigned_status`, `calendar.read`, `calendar.read_assigned`, `calendar.manage`, `customers.read_limited`, `customers.verify_identity`, `customers.recovery_token`, `payments.read`, `payments.verify`, `gifts.verify_payment`, `refunds.request`, `refunds.approve`, `loyalty.read`, `loyalty.redeem`, `loyalty.adjust`, `reviews.moderate`, `occasions.read`, `occasions.manage`, `services.manage`, `packages.manage`, `settings.manage`, `staff.manage`, `audit.read`, `reports.operational`, `reports.financial`).
- Routes: `GET /api/ops/dashboard`, `POST /api/ops/bookings/:id`, `POST /api/ops/calendar/block`, `POST /api/ops/group-requests/:id`, `POST /api/ops/gift-requests/:id`, `POST /api/ops/verify`, `POST /api/ops/recovery`, `POST /api/ops/refunds/request`, `POST /api/ops/refunds/:id/decide`, `POST /api/ops/rewards/:id`, `POST /api/ops/reviews/:id`, `POST /api/ops/services`, `POST /api/ops/packages`, `POST /api/ops/settings`, `POST /api/ops/staff`, `POST /api/ops/staff/:id`, `POST /api/ops/adjustment`.
- CLI owner bootstrap: `node server.mjs --create-owner` (`OWNER_NAME`, `OWNER_PHONE`, `OWNER_PASSWORD`). Monetary values in API SAR, SQLite integer halalas. Shared UI foundation lives solely in `packages/shared/`.
