# Integration contract
Node 24, no external dependencies, SQLite, vanilla HTML/CSS/JS. Run node server.mjs at http://localhost:3000. JSON API all responses `{...}`; failures `{error}`. Cookie sessions, same-origin mutation protection. Frontend fetch wrapper gets `/api/session` {user:null|{id,name,phone,role,verified},csrfToken} then sends X-CSRF-Token on mutations.

GET /api/catalog => {services,packages,settings,reviews}; service {id,name_ar,name_en,description_ar,description_en,price,duration,category,active}; package {id,name_ar,name_en,service_ids,price,original_total,duration,active}.
POST /api/register {name,phone,password,passwordConfirmation,terms:true}; POST /api/login {phone,password}; POST /api/logout {}. POST /api/verification/request {} => {reference,expires_at,whatsapp_url}; POST /api/reset {token,password}.
POST /api/bookings {service_ids:[],package_id:null,date:'YYYY-MM-DD',time:'HH:mm',name,phone,neighborhood,notes,terms:true,idempotency_key} => {booking,whatsapp_url,message}. GET /api/account => {user,bookings,ledger,balance,rewards,reward_requests,reviews}. POST /api/rewards/request {reward_id}; POST /api/reviews {booking_id,rating,body,display_name}.
GET /api/admin => {bookings,customers,verifications,payments,ledger,reward_requests,services,packages,reviews,settings,staff,audit,analytics}. POST /api/admin/bookings/:id {status,date,time,paid_amount,payment_method,payment_verified,refund_amount,reason}; only fields provided changed. POST /api/admin/verify {user_id,reference,observed_phone,checked:true}; POST /api/admin/recovery {user_id,observed_phone,checked:true} => {token,reset_url}; POST /api/admin/rewards/:id {booking_id,action:'commit'|'cancel'}; POST /api/admin/services {id?,...}; POST /api/admin/packages {id?,...,remove?}; POST /api/admin/settings {settings:{...}}; POST /api/admin/reviews/:id {approved:boolean}; POST /api/admin/staff {name,phone,password,role:'employee'}; POST /api/admin/adjustment {user_id,points,reason}.
Settings keys: business_phone,instagram,tiktok,areas (array),capacity (integer; 0 unconfigured),working_days [0..6],opening_time,closing_time,blocked_dates,travel_buffer,lead_hours,points_per_sar,rewards [{id,points,value}], business_approved false. Money in API SAR, database integer halalas. booking fields id,reference,name,phone,items,total,duration,date,time,neighborhood,notes,status,paid_amount,payment_verified,user_id. No historical matching by phone.
CLI owner bootstrap: node server.mjs --create-owner (environment OWNER_NAME OWNER_PHONE OWNER_PASSWORD). No default passwords. Server exports createApp({dbPath,port?}) if practical for tests; otherwise tests launch process with env DB_PATH PORT. Static fallback index.html for routes, /api always JSON. Frontend language paths /ar/... /en/.... All UI editable catalog descriptions and settings. Owner-only settings/staff/catalog/audit/financial analytics.
